# 데이터 기준

현재 원천은 공공데이터포털 **대전광역시 유기동물공고 현황** (데이터셋 `15016646`)입니다. 요청 주소는 `https://apis.data.go.kr/6300000/animalDaejeonService/animalDaejeonList`입니다. 수집기는 실제 XML의 `ServiceResult/MsgBody/items` 행을 페이지 끝까지 읽고, 페이지 행 합계를 `totalCount`와 검증합니다. 사용자 지표는 `regDtTm`(게시글 등록일)이 기준 KST 날짜인 공고만 세며, `totalCount` 전체 조회 수와 별도입니다. 구·종류·상태 집계도 이 날짜 필터를 통과한 행만 대상으로 합니다.

실응답 분류값 매핑은 `gu`: `3640000` 동구, `3650000` 중구, `3660000` 서구, `3670000` 유성구, `3680000` 대덕구; `classification`: `417000` 강아지, `422400` 고양이, `429900` 기타동물입니다. 분양상태는 명세가 설명한 1 공고중, 2 입양가능, 3 입양예정, 4 입양완료, 7 주인반환만 이름을 붙이고 다른 코드는 미확인으로 집계합니다.

실응답에서는 `numOfRows` 메타데이터가 실제 행 수와 다르게 표시되는 사례가 있어, 수집기는 이 값만으로 페이지 합계를 판단하지 않습니다. 요청한 페이지 크기·실제 행 수·`totalCount`·중복 게시물 번호를 함께 검사합니다. 게시물 번호는 검증 중 메모리에서만 사용하고 저장하지 않습니다.

`regDtTm`, `noticeDate`, `rescueDate`는 각각 게시글 등록일, 공고일, 구조일입니다. “오늘 등록된 공고 수”는 오직 `regDtTm` 기준입니다. API 전체 조회에서 게시글 등록일이 오늘인 행의 수를 계산하고 서로 다른 실제 날짜의 값을 비교합니다. 과거 날짜 조회를 API가 제공한다고 확인되지 않아 임의 날짜로 과거 재수집하지 않습니다.

홈의 주간 카드는 현재 API 응답의 `regDtTm`을 지난주 월요일~일요일로 묶은 요일별 건수입니다. 이 주간 분포는 조회 시점에 계산한 참고 집계이며, 그 과거 날짜에 저장한 스냅샷이나 T04 날짜별 비교 기록을 대신하지 않습니다.

홈의 최근 7일 그래프는 별도 `recent_7_day_registration_counts` 집계이며, 오늘을 포함한 최근 7개 `regDtTm` 날짜를 현재 API 응답에서 셉니다. 조회 기준일과 조회 시각을 그래프 아래에 표시하고, 실패 시에는 마지막 정상 그래프를 최신 현황처럼 보여주지 않습니다.

상세 응답의 게시물 번호, 등록번호, 메모, 발견장소, 사진 경로는 저장·표시하지 않습니다. 실패 시나리오는 합성 fixture로만 재생합니다.
